# Insert QR assets

Generated by `segno` — ECC **H** (30%), QR **version 4 (33×33 modules)**.
Regenerate with the script echoed in `../DECISION-MEMO.md` (§QR generation).

| File | Encodes | Card / use |
|---|---|---|
| `qr-pc.svg` / `qr-pc.png` | `https://spicyrx.com/qr/pc` | **playing-card** design (light background) |
| `qr-bc.svg` / `qr-bc.png` | `https://spicyrx.com/qr/bc` | **black-card** design (standard) |
| `qr-bc-blackcard.svg` / `.png` | `https://spicyrx.com/qr/bc` | **black-card** — same code, wide white border = the safe white panel to drop onto black |

- **SVG = print master** (vector, scales cleanly). PNG = 24×scale raster for previews/proofs.
- **Never print an inverted (white-on-black) QR.** On the black card use `qr-bc-blackcard.*`
  (dark-on-light inside a white panel). An inverted symbol fails on many camera scanners.
- **Min print size ~2 cm; prefer 2.5–3 cm.** 4-module quiet zone minimum (8 on the black-card panel).
- **Mandate:** scan BOTH codes from a REAL printed sample before the production run.
- These live under `docs/` (not `public/`) on purpose — they must not be web-served/indexed.
